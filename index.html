    🛡️ Database Backup & Recovery

    Choose how often the system creates a backup and where it stores it. Backups contain student records, marks, fees, attendance, staff records and saved letters. Keep copies outside the school computer as well.

    Important: this browser timer is only a convenience. It is NOT an independent scheduled backup. The server-side scheduled backup in the companion deployment package must be deployed and configured to run when this website is closed. Use a dedicated backup bucket (ideally in a separate Google Cloud project) and test recovery.
